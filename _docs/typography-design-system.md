# Typography & Design System

Executive typographic guidelines, spatial grid discipline, zero-pill doctrine, and dark mode color balance.

## Executive Font Pairing

We specify three purposeful typefaces:
- **Plus Jakarta Sans**: High-contrast, geometric display font for page titles and navigation.
- **DM Sans**: High-legibility, warm geometric font for body prose and tables.
- **JetBrains Mono**: Monospace font with clear ligature support for code tokens.



## Zero-Pill Discipline

To maintain executive elegance, badges and tags use subtle rounded rectangles (`rounded-md`, `rounded-lg`) rather than oval pill shapes. Metadata is presented with clean unboxed text separated by subtle middots (`·`).
