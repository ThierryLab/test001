# Data Privacy & Encryption at Rest

Enterprise data compliance, AES-256-GCM encryption, envelope key hierarchies, and audit logging standards.

## Envelope Encryption Standard

All sensitive customer records and API credentials are protected using envelope encryption. Data Encryption Keys (DEKs) are generated per document and protected by regional Key Encryption Keys (KEKs).



## Audit Trail Retention

Immutable audit logs record all identity changes and configuration updates for a minimum of 365 days in SOC2 and ISO 27001 compliant cloud buckets.
